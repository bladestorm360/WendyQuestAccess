# Field routing and collision

## Local geometry and worker

The [local bake tool](../tools/bake-world.cjs) reads the installed Steam build 26578620 under the bounded runner. It emits one byte of collision and interaction flags per cell, plus dimensions and map identity. It builds all 239 installed maps and 191,235 cells, including maps whose normal gameplay reachability remains open. The manifest hashes the input and output. Derived files stay outside Git and the development payload. The installer will need to generate them locally before enabling route commands.

[The route worker](../src/world/route-worker.cjs) verifies the geometry build and per-map hash, retains one current map, and accepts copied terrain changes, event occupancy and vehicle state. [Collision composition](../src/world/geometry.cjs) uses a maximum of 16,384 cells, 512 events and two vehicle obstacles. It keeps rectangular blockers to four updates each plus one grid pass. [Route search](../src/world/routes.cjs) finds a shortest cardinal route to a tile or an eligible on-foot event approach. It returns ordered travel legs, distance in tiles and any required final facing. Cancellation checks during geometry assembly and search discard retired results. The renderer still needs to publish live snapshots, cap outstanding requests and compare current world revision and request identity before accepting a result.

## Native movement and interactions

Walking follows stock `Game_Map.checkPassage`, `allTiles`, `isPassable` and `Game_CharacterBase.isMapPassable` in `package.nw/js/rmmz_objects.js`. Star layers yield to the next layer. The destination must also allow passage from the reverse direction. Active tile events precede the base layers in the native list order. Normal-priority events and present non-through boats and ships can occupy the destination.

`MapScene.js` `Game_CharacterBase.canPass` at original byte 107092 adds inclusive rectangular blockers. Their priority can differ from their collision state. The current event position and the rectangle offsets determine coverage. Erased and through events yield. The same custom plugin supplies `Game_Player.startMapEvent`, `canTriggerEvent` and `findEventsAt`, starting at byte 109478. The route endpoint tests native action priority and trigger, and supports the stock counter look-ahead only when the nearer tile has no startable event. Boat and ship movement use destination regions via `MapScene.js` `IsWater` at byte 11791. Region 253 is boat-only and 254 permits both. Boarding, disembarking and cross-map routing still need their own adapters.

`Tyruswoo_TileControl.js` `setExactTileId` at original byte 31297 writes the flattened layer index to the saved per-map tile-change table and updates the live map when editing locally. Autotiling can write neighboring cells through the same setter. `MapScene.js` `TileEditor.FloodFillRegion` at byte 32381 writes successive regions through that setter and yields between rings. The runtime producer must reconcile already-restored saved edits after native readiness, then retire old route results when native tiles, event pages, movement or blockers change. A partially completed flood or a moving patrol needs its own readiness and timing rule.

## Offline evidence and limits

Build with `build.ps1`, then run `tests/world.test.cjs` with Node under the bounded runner. Pass the installed root and a fresh temporary output directory outside every Git tree. The test bakes all maps, compares native movement through the extracted installed functions, and verifies route legs and arrival triggers with those same functions. Remove the temporary geometry after the test. `tests/nw-smoke.py` also loads the packaged worker in matching NW.js 0.48.4 with a synthetic map. [Build and fixture commands](implementation.md#reproduction)

- Compared **120,972** directed movements across maps 019, 062, 113, 195, 196, 199, 200, 201, 202 and 206, including repeated states. The worker reached the Salt Caverns wall clue and returned unreachable for the reset event from that fixture's origin and state. The test checked a crystal self-switch page selection and both authored flood fills in event 36. This covers native writes and resulting movement rules for the fixture states.
- Lava River used the native rectangle setter, through-state changes and the bridge edits from event 17. The resulting one-tile crossing matched native movement. Map 113 verified boat and ship rules and a present boat obstacle. The secret-cave test followed native collision and accepted event-facing from the authored entrance to the first distraction interaction on map 200. Patrol phases, detection, safety windows and reset/replay remain open.
- The resource-throttled route fixture measured 73.0 ms cold and 7.4 ms warm round trips for the Salt Caverns clue, and 44.1 ms cold and 0.3 ms warm for the changed Lava River crossing. These measurements include the fixture IPC and cold worker startup. In-game snapshot assembly, audio delivery, cumulative renderer cost and cancellation during a running disk read remain unverified.

The next connected slice is current-map admission and read-only native snapshots, followed by the first spoken route request. Use the player's native tile movement to qualify spoken distance before exposing step counts. The route worker currently runs in offline fixtures. Target names, field controls, hazards, puzzle guidance, navigation audio, autowalk and final Steam deployment remain open.
