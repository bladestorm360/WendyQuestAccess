# Pause and inventory menu access

The pause menu speaks the active command after the native menu is rendered. Inventory speaks the active category or item, its displayed quantity, availability or equipped marker where applicable. Press **I** for the current item's description and displayed equipment comparison. **Shift+Up** and **Shift+Down** move between detail lines. **Shift+Left** and **Shift+Right** jump to the first and last line. Ordinary arrows still navigate the game menu.

On a controller, press and release **View/Select**, then **A** on an Xbox layout to read details. In mod mode, the D-pad directions review the same lines or jump to the first and last line. Each review action returns the controller to ordinary menu input. The effective bindings are listed and can be changed under **Keyboard bindings** or **Controller bindings**. Under **Speech**, **Autodetail** appends the current details after focus, and **Menu indexing** adds position and count to focus and review. Both default off and persist independently. ## Native producers

The fingerprinted `MenuScene.js` for Steam build 26578620 publishes the settled pause update at original byte 12930 and inventory update at 20002. The observer waits for postrender, verifies the current scene, focus, window layer, visible content and row rectangle, then copies the active label and details. Command labels and enabled state come from the same current command row that native `Window_MenuCommand.drawItem` draws. Indexing skips the native blank command cells. Inventory's custom focus flags distinguish the category and item windows. Native item names and the quantity call follow `Window_ItemList.drawItem` at byte 34666 and the active `drawItemNumber` override at 36898. A native redraw of the selected item invalidates the old observation. `Window_Item_Help.refresh` at 79255 paints its current text, with a paint marker at 79513. The observer requires the help window to be visible and bound to the same selected item. The installed item, weapon and armor descriptions have at most 83 characters. The review buffer keeps native line order and repeated lines.

The inventory equipment pane draws four parameters in `Window_EquipStatus.drawAllParams` at 169734. The adapter reads those four labels and current and proposed values from the visible pane's actual actor and temporary actor. The marker at 39079 records which item created that temporary actor when the native help update finished. The spoken comparison gives the displayed before and after values. Old, hidden and mismatched comparisons are retired. Other stats, actor-selection announcements and the radial HUD need their own presentation checks. The observer retires stale speech on selection, redraw and visibility changes. It clamps the review cursor after a refresh of the same item and restores it if the same selection returns after settings or the native actor overlay. A new item starts at the first line. Game-thread work uses current window references and bounded copied text. It uses the existing asynchronous speech service.
