# Pause and inventory menu access

The pause menu speaks the active command after the native menu is rendered. Inventory speaks the active category or item, its displayed quantity, availability or equipped marker where applicable. Press **I** for the current item's description and displayed equipment comparison. **Shift+Up** and **Shift+Down** move between detail lines. **Shift+Left** and **Shift+Right** jump to the first and last line. Ordinary arrows still navigate the game menu.

On a controller, press and release **View/Select**, then **A** on an Xbox layout to read details. In mod mode, the D-pad directions review the same lines or jump to the first and last line. Each review action returns the controller to ordinary menu input. The effective bindings are listed and can be changed under **Keyboard bindings** or **Controller bindings**. Under **Speech**, **Autodetail** appends the current details after focus, and **Menu indexing** adds position and count to focus and review. Both default off and persist independently.
