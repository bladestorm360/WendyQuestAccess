# Cutscene audio description

Enable **Cutscene descriptions** in **F8 → Audio**. It defaults to off. The same menu sets the narration volume and speed independently of screen reader speech. The default speed is 200 percent and the default volume is 65 percent. The speed range is 80–250 percent in 10-point steps. The Mod sounds switch controls whether this playback is available. The update applies the new default to settings that still used 100 percent and preserves other saved speeds.

## On-demand descriptions

**Shift+M** describes the current map. **I** describes the selected enemy or the active dialogue speaker. Both requests use the normal screen-reader output. A battle target must still own its rendered selector and art. The speaker description uses the current displayed portrait. For portraitless map dialogue, the mod checks the visible sprite associated with the displayed speaker. Verified shared conversations can identify a different sprite than the event that started the line. Townspeople and Wendy’s staff share sprite sheets, and the renderer’s 32-pixel frame column identifies the character within each sheet. Chillcrest’s Kennick uses the white-haired, bearded frame. Joanne and Gemma share the red-headscarf frame. The lookup happens on request, uses the current rendered scene and skips hidden speakers. The Mech Grunts line in Breaded Bay uses the visible group of robots. The dialogue fixture checks both starting events for the Kennick and Joanne conversation and also checks Gemma and the Chillcrest fisherman. The appearance readout covers visible face and body features as well as clothing and gear. It plays only when requested. Unpictured or unmatched speakers get a short unavailable message. A displayed atlas or puzzle diagram retains its existing Details action. [Speaker observer](../src/dialogue/observer.js) · [Battle target details](battle.md#visual-descriptions-while-targeting)

## Playback and verification

The recording script renders the original narration text with Microsoft Zira Desktop and encodes it as mono Opus in WebM at 32 kbps. The 76-clip pack totals 893,393 bytes. Chromium plays the clips independently of NVDA. Playback requires only the shipped audio and the game's existing Chromium runtime. [Recording script](../tools/record-narration.ps1)

The pack is limited to 1 MiB and one optional asynchronous read in a settled field. The observer validates the exact native interpreter, page list and command, then confirms the movement, sprite reveal, balloon, flash or knock in a rendered frame. It checks the named actor, texture and on-screen bounds. The finale cue waits for the full-screen flash to recede. Up to eight confirmed or pending cues wait in native command order behind one playing clip. A later cue can finish animating while it waits for playback. The frame observer starts the next clip after the media element ends. Native transition, event retirement, settings entry, resize and focus loss clear the queue and playback. Native gameplay and screen reader speech proceed independently. Rapidly advancing out of the scene can retire its remaining descriptions.
