# Cutscene audio description

Enable **Cutscene descriptions** in **F8 → Audio**. It defaults to off. The same menu sets the narration volume and speed independently of screen reader speech. The default speed is 200 percent and the default volume is 65 percent. The speed range is 80–250 percent in 10-point steps. The Mod sounds switch controls whether this playback is available. The update applies the new default to settings that still used 100 percent and preserves other saved speeds.

## On-demand descriptions

**Shift+M** describes the current map. **I** describes the selected enemy or the active dialogue speaker. Both requests use the normal screen-reader output. A battle target must still own its rendered selector and art. The speaker description uses the current displayed portrait. A portraitless map line uses the accepting event's visible character sprite when its art is cataloged. The appearance readout covers visible face and body features as well as clothing and gear. It plays only when requested. Unpictured or unmatched speakers get a short unavailable message. A displayed atlas or puzzle diagram retains its existing Details action. ## Playback and verification

The bounded recording script renders the original narration text to WAV with Microsoft Zira Desktop at the installed system voice's normal rate, then encodes mono Opus in WebM at 32 kbps. The game receives a 208,890-byte pack for 52.43 seconds of narration. It uses Chromium's audio output independently of NVDA. There is no voice model or synthesis at play time. [Recording script](../tools/record-narration.ps1) · [Windows speech rendering](https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer.setoutputtowavefile?view=netframework-4.8.1) · [Chromium media playback](https://chromium.googlesource.com/playground/chromium-org-site/+/refs/heads/main/audio-video/index.md)

The pack is limited to 256 KiB and one optional asynchronous read in a settled field. Native transition entry aborts the pending request or retires the clip. The marker requires the current map interpreter, exact native page list and authored command. The observer admits one clip after the target's visible movement or sprite reveal reaches a rendered frame. It checks the named actor, current sprite texture and on-screen bounds. The finale cue waits for the full-screen flash to recede. A single media element plays from the in-memory pack and is stopped on event or scene retirement, resize, focus loss, settings entry, a replacement cue, or the end of the clip. There is no gameplay wait or narration queue. Native text and its existing screen reader pipeline can continue alongside the description. Fast dialogue advance may cut a clip short.
