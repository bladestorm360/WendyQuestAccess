# Battle access

## Command focus

During a settled battle command menu, the mod speaks the focused command. It marks commands that the game displays as unavailable. The first command in a newly opened group also identifies the battle commands. A new native focus event can speak the same label again.

Press **I** to read the current command's visible description and cost. **Shift+Up** and **Shift+Down** review individual lines. **Shift+Left** and **Shift+Right** jump to the first or last line. On a default Xbox layout, press and release **View/Select**, then **A** to read details or use the D-pad for review. Mod mode accepts one review action and returns to ordinary battle input. The bindings can be changed in mod settings. **Autodetail** appends the visible details after focus and **Menu indexing** adds position and count. Both default off. [Shared menu controls](menus.md)
