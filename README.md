# WendyQuest accessibility mod

Launch WendyQuest through Steam. Press **F8** to open accessibility settings. Use the **arrow keys**, **Enter** and **Escape** to navigate. **Help** lists your current keyboard and controller bindings.

## Field controls

- Use the game’s arrow keys or WASD to move. Use Enter or Space to interact when the game shows its prompt.
- In the default Letters layout, press **J** or **L** to browse destinations. Use **Shift+J** or **Shift+L** to change category, **K** to read the selection and **P** for directions.
- **All** combines available destinations and saved bookmarks. **NPC** lists available characters. If a Crispy Beach route stops at a floor event, take the final step manually and request directions again after control returns. Save and load bookmarks under **Navigation → Bookmarks**.
- Press **R** to repeat dialogue, **I** to read available details and **Shift+G** for supported puzzle guidance.
- On a default Xbox-style controller, use the **right stick** to browse and **left trigger** for directions. Press and release **View**, then press **A** to read the selected destination or **Menu** for settings.
